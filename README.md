# Medical Decision Analysis – Diabetes Case Study

## Overview
This project applies **medical decision analysis** using real clinical data to support decision-making under uncertainty.

A **logistic regression model** is used to estimate the probability of diabetes, and a **utility-based decision rule** is applied to recommend either early treatment or monitoring.

## Dataset
- **Pima Indians Diabetes Dataset**
- Source: UCI Machine Learning Repository
- File: `diabetes.csv`

## Files Description
- **bio_stat.pdf**  
  Theoretical part covering medical decision analysis concepts.

- **diabetes.csv**  
  Dataset used in the case study.

- **bio_stat.ipynb**  
  Python notebook containing data analysis, probabilistic modeling, expected utility calculations, and visualizations.

- **bio_stat.ipynb-Colab.pdf**  
  PDF version of the notebook for easy viewing.

## Methods
- Logistic Regression
- Expected Utility Theory
- Decision Recommendation (Treatment vs Monitoring)
- Data Visualization (Probability distribution, utility comparison, ROC curve)
